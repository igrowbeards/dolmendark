# What is this?

This is a fan port of the dolmenwood races, classes, and spells to the shadowdark system.

## What do I need to play?

In order to make use of this project you'll need the Shadowdark book and the Dolmenwood Campaign book.
Groups might benefit from the DW player book as well, but it probably isn't a hard requirement. It does have a ton of useful tables and lore though.
No rules or abilities will come from the DW books, and unless stated explicitly players should pick classes and kindreds from
the conversion, NOT from SD core.

## TL;DR - C'mon, I just want to roll some dice!
Classes: use only the classes defined in this supplement and the shadowdark wizard and thief.
Kindreds: use only the ancestries defined in this supplement unless your party are coming in to DW from outside.
